    Cómo conseguir tu exportación

    1. En ChatGPT, ve a Configuración → Controles de datos → Exportar datos.
    2. OpenAI te enviará un correo con un enlace. Descarga el .zip.
    3. Suéltalo aquí tal cual: no hace falta descomprimirlo.
    Misma lógica que el script de Python walker.py: carpetas AAAA_MM_mes, un archivo por conversación con la fecha al principio del nombre y un pruned.json con el resumen.
